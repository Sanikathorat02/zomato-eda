# Zomato Restaurant Data: Exploratory Data Analysis

## Overview
EDA of 148 Zomato restaurants using Python (Pandas, NumPy, Matplotlib, Seaborn, SciPy).

## Questions Explored
- Which restaurant type is most common?
- Do restaurants with online ordering get higher ratings?
- Does a higher cost mean a higher rating?
- Are there outliers in votes or cost?
- Do more votes go with higher ratings?

## Key Findings
- Online ordering is linked to significantly higher ratings (3.86 vs 3.49, p < 0.05).
- Votes are highly skewed, with 19 outliers.
- Rating has a moderate correlation with votes (0.49) and a weak one with cost (0.28).

## Files
- `EDA_Zomato.ipynb`: full analysis notebook
- `Zomato-data-.csv`: dataset

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Jupyter (VS Code)
